Financial Monitoring Android 1.5.0

Key changes:
- Fixed General Expenses Cancel / Delete confirmation by enabling WebChromeClient dialogs.
- General Expenses can be removed when a purchase is cancelled; the active cash movement is removed while the deleted record remains in History.
- Added offline Android notifications for Payday dates.
- Added offline Android notifications for unpaid Payday and Freelance bills / expenses due today.
- Reminder checks run around 8:00 AM daily, when the app opens, after relevant records change, and are restored after reboot / app replacement.
- Added Android 13+ notification permission handling.
- Added General Expenses as a separate value in monthly Overview summaries.
- Added General Expenses as a separate value in yearly Overview summaries.
- Added a General Expenses column to the January–December yearly breakdown.
- Actual Spending / Total Spending still includes General Expenses, so totals remain complete.
- Existing future-payday exclusion, allowance, possible-money-left, database backup, Freelance, receivables, and History behavior preserved.
